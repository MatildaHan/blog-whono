# astro-whono

一个极简的 Astro 主题。

本项目维护仓库：[MatildaHan/blog-whono](https://github.com/MatildaHan/blog-whono)。

## 开发与维护

使用 `.nvmrc` 指定的 Node 版本和 npm：

```sh
npm ci
npm run dev
```

- [项目协作规范](AGENTS.md)：修改边界、按影响验证和 Git 交付规则。
- [维护指南](docs/maintenance.md)：常用命令、专项检查、内容与部署配置说明。

后续修改完成并通过相应检查后，默认直接提交并推送到本仓库的 `main` 分支，无需逐次确认。用户明确要求只分析或不推送时，以当次要求为准。
